# ◆ TestTest — Creative Landing Page

A modern, premium landing page built with vanilla HTML, CSS & JavaScript.

![Status](https://img.shields.io/badge/status-live-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)

## ✨ Features

- **Dark Theme** — Sleek dark UI with purple/blue accent gradients
- **Glassmorphism** — Backdrop blur and translucent elements
- **Smooth Animations** — Scroll reveals, floating orbs, parallax mouse tracking
- **Animated Counters** — Stats count up when scrolled into view
- **Contact Form** — Interactive form with loading & success states
- **Fully Responsive** — Mobile-first, works on all screen sizes
- **No Dependencies** — Pure HTML + CSS + JS, no frameworks needed

## 🚀 Quick Start

Simply open `index.html` in your browser:

```bash
open index.html
```

Or serve locally:

```bash
npx serve .
```
